# EdTech Interactive Coding Sandbox & STEM Lesson Dashboard

A full-stack web application designed for K-12 students and educators, combining an interactive coding playground with a structured curriculum tracker and educator analytics dashboard.

## Tech Stack
* **Frontend:** React.js, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB / PostgreSQL (via Supabase)

## Project Structure
- `/client` - React frontend application
- `/server` - Node.js backend API and execution environment
